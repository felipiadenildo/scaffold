Uso contínuo, não é pra preencher tudo de uma vez, é um registro vivo. Princípio completo em [Planejamento de Médio e Longo Prazo](/manual/08-planejamento-medio-longo-prazo/): a revisão orienta o futuro, não julga o passado.

## Revisão semanal: dez minutos, mesmo dia toda semana

Ritual de abertura: uma bebida gostosa, um lugar confortável, para associar a revisão a algo bom.

```
Semana de ___/___ a ___/___

O que funcionou essa semana?
-

O que não funcionou?
-

O que muda pra semana que vem?
-

Uma vitória da semana, por menor que seja:
```

## Revisão mensal: auditoria realista, não lista de cobrança

```
Mês: ______________

Compromissos assumidos vs. energia real disponível: bateu?
-

A Folha A5 ainda está ajudando ou virou obrigação?
-

O quadro de cortiça está com as três zonas limpas ou acumulando?
-

Algum sistema foi abandonado esse mês? Em qual ponto? (dado útil, não motivo de culpa)
-

Ajuste para o mês que vem:
-
```

## Histórico

Copie o bloco acima a cada semana ou mês, indo pra baixo neste arquivo, ou mova pra uma página no Notion, se preferir buscar por data depois. Não é pra reler tudo sempre; é pra consultar quando algo se repetir e você quiser confirmar se é mesmo um padrão.
