O Scaffold é um material de referência prático, não um artigo acadêmico, mas cada página cita as fontes que embasam o que está escrito. Se você quiser referenciar este manual, ou um capítulo específico dele, em outro trabalho, use o formato abaixo.

## Citando o manual inteiro

```
Scaffold: manual de rotina e ambiente para TDAH. Versão [ver Changelog para a data].
Disponível em: [URL do site]. Acesso em: [data de acesso].
```

## Citando um capítulo específico

```
[Título do capítulo]. In: Scaffold: manual de rotina e ambiente para TDAH.
Disponível em: [URL do capítulo]. Acesso em: [data de acesso].
```

## Citando uma fonte original mencionada aqui

Sempre que possível, prefira citar a fonte original listada na seção "Fontes" de cada capítulo, não o Scaffold como intermediário. O objetivo deste manual é reunir e traduzir para a prática, não substituir a literatura de origem.

Por exemplo, para citar o conceito de ponto de performance, a referência correta é Russell A. Barkley, não este manual.
