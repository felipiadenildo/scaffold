Este é o **manual**. Não é o aplicativo, nem a folha pronta para preencher no celular. Isso vem depois, como projeto separado. Aqui está o raciocínio por trás de cada peça do sistema, os templates para imprimir e usar hoje, e as fontes que sustentam cada recomendação.

Não é para ler do início ao fim. Abra, ache a parte que resolve o problema de agora, feche. Cada capítulo é curto de propósito. Templates ficam separados da teoria: quem só precisa da folha de amanhã não devia ter que ler um capítulo inteiro para chegar nela.

O **Cartão SOS** está marcado com um selo vermelho de "crise" na barra lateral, dentro de Templates prontos. Não é preciso ler nenhum outro capítulo para achá-lo.

## Como o manual é organizado

- **Manual.** Capítulos de referência. Cada um explica um tema: por que ele importa, o que fazer, o que evitar, e com que embasamento.
- **Templates prontos.** Ferramentas para usar esta semana: Folha A5, lista de compras, meal prep, viagem, financeiro, e o próprio Cartão SOS.
- **Guia de produtos.** O que comprar, onde encontrar, faixa de preço.
- **Implementação.** Checklist de execução e registro de revisão contínua.

Veja também o [Resumo](/resumo/) e o [Glossário](/glossario/).
